# k (`top` kill prompt)
## Overview
In interactive top, k prompts for a PID and signal to send; verify the target before confirming.

## Common Usage
Inspect or use the concept with this practical Linux command:

```bash
top
```

Verify the target and command result before making production changes.

## SRE Relevance
For Site Reliability Engineering (SRE), correlate state and resource use with service health; prefer supervised, graceful changes and verify recovery.

Example: top
