# groups
## Overview
groups prints the groups available to the current or specified user; id additionally reports numeric identifiers.

## Common Usage
Inspect or use the concept with this practical Linux command:

```bash
groups appuser
```

Verify the target and command result before making production changes.

## SRE Relevance
