# `ls`

I use `ls` in a terminal to list files and folders in the current directory.
I can also give it a path:

```text
ls
ls path/to/folder
```

On macOS, Linux, and Unix-like shells, `ls -a` also shows hidden files. In
PowerShell, `ls` is an alias for `Get-ChildItem`; I can use
`Get-ChildItem -Force` to show hidden files.

`ls` is a terminal command, not a Python function.
