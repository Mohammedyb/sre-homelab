# Operators are used to perform operations on variables and values.

# Arithmetic Operators

## Addition +
- Use + to calculate the sum of two or more numeric values.

## Subtraction -
- Use - to calculate the difference between two numbers.

## Multiplication *
- Use * to multiply two or more values.

## Division /
- Use / to divide one value by another.

## Modulus %
- Use % to return the remainder left over after dividing the left value by the right value.

## Exponentiation **
- Use ** to raise one number to the power of another.

## Floor Division //
- Use // to divide two numbers and round the result down to the nearest whole number.

# Comparison Operators

## Equal to ==
- Use == to check whether two values are equal.

## Not Equal to !=
- Use != to check whether two values are not equal.

## Greater Than >
- Use > to check whether the left value is greater than the right value.

## Less Than <
- Use < to check whether the left value is less than the right value.

## Greater Than or Equal to >=
- Use >= to check whether the left value is greater than or equal to the right value.

## Less Than or Equal to <=
- Use <= to check whether the left value is less than or equal to the right value.

# Logical Operators

## or
- use 'or' to combine multiple comparisons. atleast one needs to be true for whole statement need to be true.

## and
- Both comparisons need to be true for the if statment to be true.

## not
- lets you negate a comparison. And can help make the statement more readable.
