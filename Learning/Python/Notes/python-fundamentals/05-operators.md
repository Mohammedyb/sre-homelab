# Operators are used to perform operations on variables and values.

# Arithmetic Operators 

## Addition +
- use '+' to calculate the sum of two or more numeric value

## Subtraction - 
- use '-' to used to calculate the difference between two numbers

## Multiplication *
- use '*' to multiply values

## Division /
- use '/' to divide values

## Modulus %
- use "%" to  return the remainder left over after dividing the left number by the right number

## Exponentiation **
- use '**' for exponentiation, which means raising one number to the power of another.

## Floor Division //
- use '//' to  divide two numbers and round the result down to the nearest whole number
