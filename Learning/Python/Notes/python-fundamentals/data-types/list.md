# Lists

A list stores an ordered collection of items. It can be empty, contain one
kind of item, mix different kinds of items, or contain other lists.

```python
empty = []
names = ["Ada", "Grace"]
mixed = ["score", 10, True]
nested = [[1, 2], [3, 4]]
```

List indexes start at `0`, so the first item is at index `0`.
