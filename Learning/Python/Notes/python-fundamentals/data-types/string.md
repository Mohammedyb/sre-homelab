# Strings

A string (`str`) stores text. Create one by putting text inside single or
double quotes.

```python
name = "Python"
message = "It's a useful language"
```

Use double quotes when the text contains an apostrophe, or escape the
apostrophe inside single quotes.

## Concatenation

The `+` operator joins strings. Add a space explicitly when one is needed:

```python
full_name = "Ada" + " " + "Lovelace"
```
