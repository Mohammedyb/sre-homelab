# A conditional statement or an if statement lets us make decisions in Python

## if Statement 
- Lets us decide what to do: if True, then do this. 
    -- any indented code that comes after an if statement is called a code block. its what is run if statement is true.
    -- Something to look out for in Python is indenting code blocks. Usually four spaces are used, and if the whitespace is not consistent and you then use two spaces somewhere else, you'll get an indentation error. 

## else Statement 
- Will run when the if statement is false.

## elseif statement elif
- allows you to check multiple, sequential conditions if the initial if statement evaluates to False.

# Logical Operators

## or
- use 'or' to combine multiple comparisons. atleast one needs to be true for whole statement need to be true.

## and
- Both comparisons need to be true for the if statment to be true.
